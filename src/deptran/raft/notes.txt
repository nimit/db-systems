RRR framework

Define functions as fast/defer
fast -> quick, non-blocking RPC (e.g., __reset__wrapper__)
defer -> async, heavier and blocking task (would be executed in one coroutine) (e.g., __increment__wrapper__)

Use defer as much as possible

rrr::PollMgr* poll = new rr::PollMgr(1) -> Continuously checks for new tasks to perform
ThreadPool -> (initialize same as pollmgr) Actually executes the command
Server -> Initialize with objects of PollMgr and ThreadPool

PollMgr -> important!!!
